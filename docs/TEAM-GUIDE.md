# World Clock Team Guide

The foundation is deliberately small so everyone can work without stepping on another person's code.

## Workflow

1. Pull the latest main branch.
2. Create a branch for your task, for example: feature/time-converter.
3. Work only on the files needed for your task.
4. Test the change in the browser.
5. Commit with a clear message.
6. Push your branch and open a pull request.

## Suggested work areas

- Header and navigation
- Search and city filtering
- Add Clock flow
- Clock card UI
- Time-zone converter
- Responsive/mobile polish
- Accessibility
- Testing and bug fixes
- Documentation
- Deployment

## File ownership

- index.html: shared page structure
- css/style.css: shared visual design
- js/app.js: live clocks and interactions
- docs/: team notes and documentation

Coordinate before rewriting another teammate's section. Prefer small, reviewable changes.
